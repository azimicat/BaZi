# 四季の命式

生年月日、出生時刻、日本国内の出生地、性別から命式と鑑定文を表示する静的サイトです。
スマホの縦画面を中心に設計しています。
入力内容はブラウザ内で計算し、サーバーや外部APIへ送信せず、保存領域やURLにも残しません。

## ローカルで確認する

Node.js 22.12以降と pnpm 10.33.1 を使用します。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

画面に表示されるローカルURLを開いてください。

```sh
pnpm test
pnpm build
pnpm preview
```

`pnpm build` は型検査を実行し、配信用ファイルを `dist/` に出力します。
`pnpm preview` はビルド済みの画面を確認するためのサーバーです。

## GitHub Pages で公開する

1. [azimicat/BaZi](https://github.com/azimicat/BaZi) の `main` ブランチにプッシュします。
2. リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定します。
3. **Actions → GitHub Pages → Run workflow** を実行します。以後は `main` へのプッシュでも公開されます。
4. 公開URLは Actions の `deploy` ジョブと Settings → Pages に表示されます。

公開設定は `.github/workflows/pages.yml` にあります。
既定ブランチが `main` 以外の場合は、ワークフローの `branches` を合わせてください。
`base: './'` と相対パスを使用しているため、リポジトリ名のサブパスでも独自ドメインでもファイルを読み込めます。
公開先リポジトリは `azimicat/BaZi` です。GitHub Pages の配信元設定はリポジトリ側で確認してください。

[GitHub の公開手順](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)

## 表示する内容

- 年柱、月柱、日柱、時柱、蔵干、通変星、十二運
- 天干と地支の本気による五行の構成
- 日干を中心にした性格、仕事、恋愛の説明
- 現在の年運から10年分の年運、10期分の大運
- 出生時刻不明時の三柱、命式の候補、大運開始年齢の幅
- 入力見直しと印刷

## 計算規則と鑑定の範囲

子平法を基礎に、採用した計算規則を画面内の「鑑定を読む前に」に掲載しています。
年柱は立春、月柱は各節入りの瞬間で切り替えます。
節入りは同じ瞬間で全地点共通とし、出生地補正では動かしません。
日柱は出生地の地方平均太陽時の午前0時に切り替えます。
時柱は23時開始の2時間区分で、23時台の時干も当日の日干から求めます。

出生時刻は日本の出生記録上の時刻として解釈します。
1948〜1951年の夏時間を `Asia/Tokyo` の時差情報で考慮し、東経135度との差1度につき4分を補正します。
均時差を加える真太陽時には対応していません。
夏時間開始によって存在しない時刻と、夏時間終了によって二度現れる時刻は、時刻を指定した鑑定の対象外です。

生年月日の入力範囲は1900年1月1日から閲覧当日までです（収録上限は2099年12月31日）。
年運は立春で切り替わります。
大運は年干の陰陽と性別から順逆を決め、節入りまでの日数を3日＝1年で換算します。
大運の開始年齢と西暦は近似値です。

出生時刻が不明な場合は正午を仮の基準にし、時柱を省きます。
出生日の開始時刻と終了時刻、節入り前後の候補も確認して、命式の候補と開始年齢の幅を示します。
日柱や月柱が変わる候補では鑑定文も変わるため、表示中の鑑定文が確定結果ではない旨を案内します。

鑑定文は `src/content.ts` の文章を、日干と通変星に応じて組み合わせます。
格局、用神、身強身弱、合冲の総合判断は含みません。
五行の数を強弱や吉凶の点数として表示しません。

## 暦と市区町村の更新

節入り時刻はビルド時に外部から取得せず、同梱した一覧を使用します。
`lunar-javascript` の時刻はUTC+8として読み、UTCへ変換して収録します。

```sh
pnpm generate:terms
```

市区町村の代表経度は Geolonia の `latest.csv` に含まれる町丁目の経度の算術平均です。
未収録の利島村と湯前町、区再編後の浜松市中央区と浜名区は国土地理院の代表地点を用い、旧6区を除外しています。
補完内容は `scripts/city-overrides.json` に記録しています。
出生施設の経度とは差があり、市区町村名は取得時点の掲載内容に依存します。
CSVを取得したあと、pyenvで選択したPythonから次のコマンドを実行して更新できます。

```sh
python3 scripts/generate-cities.py /path/to/latest.csv
```

更新後は `public/THIRD_PARTY_NOTICES.txt` の取得日と、本書の市区町村数を更新してください。
暦ライブラリと住所情報の利用条件は `public/THIRD_PARTY_NOTICES.txt` に記載しています。
写真、ロゴ、草花の図版は参考サイトから転用していません。

## 検証

立春と小寒の前後、午前0時、23時台、経度補正での日付変更、夏時間、閏日、未来日付、時刻不明時を自動検証します。
日柱は1900〜2026年の参照日について暦ライブラリと照合しています。
節入り時刻は暦ライブラリの計算値であり、全収録年を公的な暦表と照合したものではありません。

## 共有時の画像

Slackなどのリンクプレビュー向けに、HTML内へOGPとTwitter Cardのメタ情報を設定しています。
共有用の画像は `public/og-image.png`（1200 × 630）です。
既存の草花SVGを使い、次のコマンドで再生成できます。
生成時には日本語を表示できる明朝体フォントが必要です。
生成済みのPNGを同梱しているため、GitHub Actionsでの画像生成は不要です。

```sh
pnpm generate:og
```

公開ドメインやパスを変える場合は、`index.html` のcanonical、OGP、Twitter Cardの絶対URLも更新してください。

## A4一枚の印刷

鑑定結果の「結果を印刷する」から、A4縦一枚の印刷用レイアウトを開けます。
左側に命式、五行、性格、仕事、恋愛を、右側に今年のテーマ、10年分の年運、10期分の大運を配置します。
各年の年運はテーマのみを掲載します。
出生時刻不明などの注意文がある場合も注意文を残し、印刷範囲に合わせて縮尺を調整します。
印刷設定はA4、縦向きを選んでください。
画面用の表示と印刷用の表示は `src/print.ts` と `src/print.css` で分けています。

## 画面の文字サイズ

画面幅601px以上では、鑑定文と紹介文は17px、入力欄と操作は16px、補足文と命式表は14pxを基準にしています。
本文の行高は文字サイズの1.85倍で、文字サイズはremで指定しています。
画面幅600px以下のスマホでは、鑑定本文14px、紹介文13px、補足文11pxを中心に、従来から1〜2pxの拡大にとどめています。
見出し、段組み、余白は従来の構成を維持しています。
`src/typography.css` は画面専用で、A4印刷用の組版には適用しません。
目安は[デジタル庁のタイポグラフィ](https://design.digital.go.jp/dads/foundations/typography/)と[GOV.UKの文字サイズ](https://design-system.service.gov.uk/styles/type-scale/)を参考にしています。
